ChatIRC v0.1.0 - Release Notes

What's new
- Initial public release of ChatIRC: a curses-based IRC-style client for interacting locally with OpenAI chat models.
- Features:
  - Per-room chat logs and message history
  - Slash commands, tab completion, Unicode-aware wrapping
  - Background API calls for responsive UI
  - Persistent input history and atomic history writes

How to get it
- Download the binary for your platform from the GitHub Releases page.
- Alternatively, clone the repository and run from source (see README).

Installation for binary users
- Download the `chatirc` binary for Linux (or the appropriate binary for your OS)
- Make it executable: `chmod +x chatirc`
- Run: `./chatirc`

Payment / Donation (Gumroad)
- Create a Gumroad product (free or paid) and upload the binary as a 'file'.
- Configure the product so buyers receive the GitHub release URL or a direct download link after purchase.
- Recommended text for Gumroad product description:

"ChatIRC — a compact, keyboard-first terminal client for OpenAI chat models. License includes free updates for minor releases. Please place your OpenAI API key into `~/.chatirc/openapi_key` or `openapi_key` in the working directory."

Security & notes
- Do not share your OpenAI key. The product does not collect user data.

Support & contact
- For issues, please open a GitHub issue on the repository.

*** End Release Notes
